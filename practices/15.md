# Claude Code 使用国内中转站

## 1、安装Claude Code
Mac
```shell
curl -fsSL https://claude.ai/install.sh | bash
```
npm
```shell
npm install -g @anthropic-ai/claude-code
```

Windows
```shell
irm https://claude.ai/install.ps1 | iex
```

## 2. 配置
vim ~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_AUTH_TOKEN": "xxxxxxx",
    "ANTHROPIC_BASE_URL": "https://xxxxxx"
  },
  "theme": "dark"
}
